# 目标电脑验收

按真实设备操作。只有相应步骤通过，才将其标为现场可演示能力。

| 顺序 | 操作 | 通过条件 |
|---|---|---|
| 1 | Ubuntu 24.04 完成依赖与本地模型准备，启动 `bash scripts/start-local.sh`，浏览器打开 7788 | 空白历史可用，无预置真实数据；计时、暂停、结束和打卡均反馈 |
| 2 | 启动 Kit + `.fuiapp` | 真实模拟器三行 HUD 出现；导航动作与网页同步 |
| 3 | 启动 Windows 窗口采集器，选择 Flow | Code 与浏览器间切换后应用名及切窗次数变化 |
| 4 | 保持计时，暂时停止采集器 90 秒 | 有效模式回到 Lite；计时继续，历史未丢 |
| 5 | 模型下载完成，启动视觉服务 | 网页识别服务显示可用；非仅启动进程即算通过 |
| 6 | 选择电脑内置摄像头，调整角度与裁剪区域，选择 Vision 并开启 | 实际送入模型的画面包含目标物品；三次一致后显示粗分类及证据 |
| 7 | 改变场景或盖住镜头 | 不立即闪烁标签；低分/无效画面不制造已确认活动 |
| 8 | 关闭摄像头/断开设备 | 轨道停止，旧场景失效，使用剩余来源；没有继续上传 |
| 9 | 右键或网页录音、结束 | 音频保存可播放；本地转写填入同一打卡，计数不重复 |
| 10 | 拒绝录音授权、断网 | 计时/主动记录仍可用；模型已准备时语音仍可离线处理 |
| 11 | 修正一个时间段，导出 JSON / Markdown | 新标签与原始证据同时保留；日期和统计一致 |
| 12 | 服务重启 | 历史保留，计时暂停恢复，摄像头默认关闭 |
| 13 | 点击本地朗读复盘，分别选择电脑/眼镜 | 对应端播放本地合成 WAV；另一端不会重复播放；眼镜可用 `/stop` 停止 |
| 14 | 暂停语音服务后录音，再恢复服务并重试转写 | 原始录音不丢失；转写更新原打卡，未新增重复项 |

视觉验证请用自己的 20–30 个桌面场景，记录真实标签、预测、未知比例和耗时；先确保阅读、书写、电脑工作可区分，再决定是否展示会议/运动标签。文档中先前的时延、CPU 占用和识别准确率均不是已完成实测。

工具包支持的真实图形/输入链路是赛事验收必需项，浏览器 HUD 预览不能替代。
