## 真实本地语音模型

已下载并加载 faster-whisper small/int8 与 Piper huayan-medium，CPU 2 线程。

合成文字：“今天完成了二十五分钟的阅读。接下来，我要休息五分钟。”

实际转写：“今天完成了25分钟的阅读接下来我要休息5分钟”。

已运行真实主服务全链路：`/api/speech` 合成 → 取回 WAV → 重采样为 PCM16k → `/api/voice` 保存 → 自动本地 ASR → 原打卡文字更新。仅新增一次打卡；本次全链路约 7.081 秒。直接合成/转写的一次观测分别约 0.805 秒/4.057 秒。这是合成语音样本的成功验证，不是目标电脑时延或真实麦克风准确率承诺。
